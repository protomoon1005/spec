# 한국어 투자 전략 명세화 · 백테스트 — 데모 (v0.2)

## 이 저장소
한국어 매매 전략 문장을 전략서(JSON)로 바꾸고, 규칙 기반 판정·검사를 거쳐
결정론적 백테스트까지 보여주는 데모. 메인 저장소로 옮기기 전 시험판이다.

## 기준 문서 (우선순위 순)
1. docs/strategy-spec-v0.2.md — 팀 확정 명세. 이 문서와 다르게 만들지 않는다.
2. docs/demo-scope.md — 데모에서 빼거나 단순화하는 것 (이 목록 외에는 v0.2를 그대로 따른다)
3. docs/demo-spec.md — 이전 판. 참고만 한다. v0.2와 충돌하면 v0.2가 이긴다.

## 절대 규칙
- LLM은 문장을 빈칸에 나눠 담는 일만 한다. 빈칸마다 상태(채워짐/말 안 함/애매함/못 다룸)와
  원문 근거를 적는다. "바로 진행 / 되묻기 / 거절" 판정과 전략서 조립은 규칙 코드가 한다.
- 검사(5단계)·재서술·백테스트에는 LLM을 쓰지 않는다. 재서술은 문장 틀에 값을 끼운다.
- 전략서는 v0.2의 사전에 있는 값만 쓴다. 사전에 없는 지표/연산자를 추가하지 않는다.
- 오늘 종가로 판단하고 다음 날 시가에 체결한다. 같은 날 사기·팔기 조건이 둘 다 참이면 팔기 우선.
- 같은 전략서 + 같은 데이터 = 같은 결과. random 금지. 미래 참조 테스트는 항상 통과해야 한다.
- 데모 수준만 만든다. 로그인, DB 서버, Docker, 실거래 연결은 만들지 않는다.
- 설계 판단이 필요하면 임의로 정하지 말고 선택지를 제시하고 멈춘다.

## 환경
- 주 개발기는 Windows PowerShell, 보조는 macOS. 두 곳에서 다 돌아야 한다.
  bash 전용 문법(&&, heredoc, make)을 검증 절차에 쓰지 않는다.
- Python 3.11+, 가상환경 .venv, 의존성은 requirements.txt.
- LLM: 호스트 Ollama qwen3:8b (http://localhost:11434), 구조화 출력, temperature 0, seed 42,
  think: false, num_ctx 16384.
- UI: Streamlit 한 개 앱 (app.py). 대화형(채팅) 화면.
  특정 회사 로고·브랜드명은 넣지 않는다.

## 명령
- 실행: streamlit run app.py
- 테스트: pytest -q
- 평가: python -m eval.run
- 비교 대상(LLM 코드 직접 생성)과 나란히: python -m eval.run --baseline → eval/report_baseline.md
