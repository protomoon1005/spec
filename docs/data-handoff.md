# 추가 데이터 인수인계 (3단계 담당: 하늘)

- 작성 2026-11-02
- 팀원이 FinanceDataReader 로 받은 5년치 수정주가 OHLCV 외에 3단계에 필요한 데이터를 모은 결과다
- 데이터 파일(약 230MB)은 크기 때문에 저장소에 넣지 않았다. 팀 드라이브에 extra-data-2026-11-02.zip 으로 공유한다(압축 81MB, 풀면 약 230MB). 날짜별 원본 raw/ 와 가상환경은 묶음에서 뺐다
- 아래 out/ 은 공유 묶음 안의 폴더다. 파일별 받은 날짜, 소스, 기간, 행 수, 종목 수, sha256 은 out/meta.json 에 있다. 수집 스크립트는 scripts/, 날짜별 원본은 raw/ 에 있다

## 먼저 알아야 할 것

- 2026-11-02 01:16 쯤 KRX 정보데이터시스템이 수집에 쓴 PC 의 IP 를 1일간 차단했다. 자동화 대량 조회로 판단됐다
- KRX 이용약관 제10조 제2호가 자동화 수단을 통한 수집을 금지한다. pykrx 는 이 시스템을 자동으로 조회하는 라이브러리라 같은 문제가 있다
- 그래서 남은 수집은 pykrx 로 이어 받지 않는다. 공식 경로를 쓴다
  - KRX Open API (openapi.krx.co.kr, 무료 가입 후 인증키). 시가총액, NAV, 업종 같은 칸을 실제로 주는지는 아직 확인하지 않았다
  - 공공데이터포털 금융위원회 주식시세정보, 주식배당정보 (무료 키)
- FinanceDataReader 도 소스에 따라 KRX 를 조회한다. 5년치 가격을 다시 받을 일이 있으면 같은 점을 고려한다

## 받은 것

- out/index_daily.csv
  - 코스피(1001), 코스닥(2001), 코스피200(1028) 일별 시가, 고가, 저가, 종가, 거래량, 거래대금, 상장시가총액
  - 2021-11-01 부터 2026-10-30 까지 각 1,223일, 결측 없음
- out/trading_days.csv
  - 거래일 1,223일. 코스피 지수가 있는 날을 거래일로 썼다
- out/vix_daily.csv
  - FRED VIXCLS 일별 종가, 2021-11-01 부터 2026-10-29 까지 1,304행
  - source_date 는 미국 날짜다. 국내 날짜에 붙일 때는 source_date 가 그 날보다 앞선 가장 최근 값을 쓴다(국내 t일 판단에 미국 t-1일 종가)
- out/listing_kind.csv
  - KIND 상장법인목록. 2,762사(코스닥 1,826, 유가 829, 코넥스 107)의 상장일과 KIND 업종
  - 회사 단위라 보통주 코드만 있다. ETF 는 없다
- out/security_flags.csv
  - 우선주, 스팩, 리츠 표시. 2,900코드
  - 우선주는 코드 끝자리가 0 이 아닌 것(5, 7, 9, K, L, M). 이름에 '우' 가 들어가는지로 찾으면 '연우' 같은 오탐이 난다
  - 스팩은 이름('스팩', '기업인수목적') 또는 소속부 'SPAC(소속부없음)'. 스팩과 합병해 같은 코드가 실제 회사가 된 24개는 was_spac_dept_ever 칸으로 따로 표시했다
  - 리츠는 이름에 '리츠'(메리츠 제외)
- out/market_cap_daily.csv (일부만)
  - 개별주 일별 시가, 고가, 저가, 종가, 거래량, 거래대금, 시가총액, 상장주식수, 시장, 소속부, ISIN
  - 2021-11-01 부터 2023-12-06 까지 520 거래일만 있다. 2023-12-07 이후 703 거래일이 빠졌다
  - 가격은 수정 전 실제 가격이다. FinanceDataReader 가격은 수정주가다. 신세계I&C(035510) 10:1 분할 전 구간에서 FDR 값이 정확히 0.1배였다. 두 파일의 가격을 섞어 쓰지 않는다
  - market 칸에 KOSDAQ GLOBAL 이 따로 나온다. 영문이 섞인 코드가 25개 있다
  - no_trade 칸: 거래량 0 이고 시가, 고가, 저가가 0 인 행. 거래정지와 단순 무체결은 구분되지 않는다
- out/etf_daily.csv (일부만)
  - ETF 일별 NAV, 시가총액, 순자산총액, 상장좌수, 기초지수명, 기초지수 종가, 가격, 거래량, 거래대금
  - 2021-11-01 부터 2023-12-05 까지만 있다. index_close 결측 19,126행

## 못 받은 것

- 개별주와 ETF 의 2023-12 이후 시가총액, 거래대금, 상장주식수, NAV
- 날짜별 업종 분류 스냅샷과 업종 변경 구간
  - 2026-11-02 에 따로 받아 둔 4개 날짜 스냅샷만 있다: 2023-01-02 와 2025-12-30 의 코스피, 코스닥 업종 분류. 평가 데이터셋 참조 파일(eval/ref/)에 같은 파일이 있다
  - 2024-06-28 과 2024-12-30 사이에 업종 체계가 개편됐다(코스닥 32개에서 25개, 코스피 24개에서 26개). 개편 날짜는 일 단위로 확정하지 못했다
  - 2026 년 하반기부터 KRX 자체 산업분류 KRICS 가 대표지수에 적용된다. 종목별로는 1, 2단계만 공표된다
- ETF 상장일. KRX ETF 기본정보(MDCSTAT04601)의 LIST_DD 칸에 있는 것까지만 확인했다
- 배당 이벤트
  - 추천 소스: 공공데이터포털 금융위원회 주식배당정보(배당기준일, 지급일, 배당금). 배당락일 칸은 없다. 기준일 1영업일 전으로 계산할 수 있어 보이지만 KRX 기준을 확인하고 써야 한다
  - yfinance 는 키 없이 배당과 분배금 이벤트가 나오지만 비공식이라 쓰지 않았다
- 거래정지 이력. 무료 이력 소스를 찾지 못했다. 위 no_trade 칸이 대안이다

## 3단계에서 정할 것

- 남은 시가총액, 업종, ETF 상장일을 KRX Open API 나 공공데이터포털로 받을지, 범위를 줄일지
- 업종 개편 전후를 instrument_history 에 어떻게 나눠 넣을지
- 종목 고르기("시가총액 큰 순")에 쓸 시가총액을 어느 파일에서 가져올지. 수정 전 가격 기준 시가총액이라 그대로 쓰면 된다
