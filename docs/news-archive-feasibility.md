# 과거 뉴스 아카이브 확보 가능성 조사 (T10)

조사 2026-09-12 · 담당 M3 강준 · 대상 구간 **2023-01-01 ~ 2025-12-31** (데모 계획 1.4)

> **판정: 3년 확보 불가. 2년으로 줄여도 해결되지 않는다.**
> 조사한 어떤 경로도 2023-01 이후 국내 금융 뉴스를 **발행 시각과 함께** 주지 않는다.
> 백테스트 구간 축소로 풀리는 문제가 아니므로, 아래 권고를 팀이 결정해야 한다.

## 왜 이게 급한가

기사가 없으면 감성 관점이 백테스트 전 구간에서 중립(`raw_score 0.0`,
`calibrated_prob 0.5`)만 반환한다. 그러면 **3관점 경연이 사실상 2관점 경연으로 줄고**,
Hedge 가중치에서 감성은 매일 같은 Brier 손실(0.25)을 받아 하한 0.10 근처에 고정된다.
"세 관점이 경쟁해 가중치가 갈린다"는 데모의 핵심 장면이 성립하지 않는다.

## 조사 방법과 한계

실제로 호출하고 받아서 잰 것만 적는다. 다음 두 가지는 **자격 증명이 없어 이 세션에서
검증하지 못했다** — 표에 "미검증"으로 표시했다.

- 빅카인즈(한국언론진흥재단) API — 기관 회원 신청·승인이 필요하다
- 네이버 뉴스 검색 API — 애플리케이션 등록(Client ID/Secret)이 필요하다

## 1. RSS — 과거를 주지 않는다 (실측)

5개 소스를 실제로 받아 항목별 `published_at` 을 파싱했다 (2026-09-12 기준).

| 소스 | 항목 수 | 유효 | 가장 오래된 항목 | 피드가 덮는 구간 |
|---|---|---|---|---|
| 연합뉴스 경제 | 120 | 120 | 2026-09-11 01:11 UTC | 1일 7시간 |
| 한국경제 경제 | 50 | 50 | 2026-09-11 08:13 UTC | 1일 3시간 |
| 한국경제 증권 | 50 | 50 | 2026-09-10 23:00 UTC | 1일 8시간 |
| 매일경제 경제 | 50 | 50 | 2026-09-10 08:29 UTC | 2일 1시간 |
| 매일경제 증권 | 50 | 50 | 2026-09-10 08:56 UTC | 1일 21시간 |

**RSS 가 주는 과거는 최대 2일이다.** 추정이 아니라 실측이다. 합계 320건을 받아
308건이 적재됐고 12건이 중복(정확 일치)으로 걸러졌다 — **하루 약 150건** 규모다.

접근 실패 2건:

| 소스 | URL | 결과 |
|---|---|---|
| 연합뉴스 증권 | `https://www.yna.co.kr/rss/stock.xml` | HTTP 404 (경로 없음) |
| 이데일리 | `https://rss.edaily.co.kr/edaily_news.xml` | Connection reset by peer |

## 2. 공개 데이터셋 — 구간이 어긋난다 (실측)

HuggingFace 데이터셋 API 로 검색하고, 후보의 **스키마와 날짜 표본을 실제로 조회**했다.

| 데이터셋 | 행수 | 날짜 컬럼 | 실측 구간 | 라이선스 | 판정 |
|---|---|---|---|---|---|
| `makedelta/kospi100_news` | 322,070 | `date` (YYYYMMDD) | **2020-01 ~ 2022-12** | **미표기** | ✗ 구간이 2023-01 직전에 끝난다 |
| `daekeun-ml/naver-news-summarization-ko` | 27,400 | `date` (초 단위) | **2022-07 한 달** | Apache-2.0 | ✗ 한 달뿐 |
| `sigridjineth/korean-news-small` | 1M~10M | **없음** (`text` 만) | — | 미표기 | ✗ 시각이 없어 as-of 불가 |
| `hugmanskj/korean-news-topic-classification` | 1K~10K | 없음 | — | CC-BY-4.0 | ✗ 시각 없음 |
| `sieu-n/korean-newstext-dump` | 1M~10M | 없음 | — | 미표기 | ✗ 시각 없음 |
| `91veMe4Plus-Project/korean_news_corpus` | 표본 28만 | 없음 | — | MIT | ✗ 시각 없음 |

두 가지가 반복해서 걸린다.

1. **대부분의 한국어 뉴스 데이터셋에 발행 시각이 없다.** 언어모델 학습용 말뭉치로
   만들어져 본문만 있다. 시각이 없으면 as-of 규약을 지킬 수 없고, 시점 무결성이
   깨진 감성 점수는 백테스트 전체를 무의미하게 만든다. **쓸 수 없다.**
2. **시각이 있는 두 데이터셋은 구간이 우리 창과 겹치지 않는다.** `kospi100_news` 는
   KOSPI100 종목별 뉴스에 감성 라벨까지 붙어 있어 내용상 가장 알맞지만
   **2022-12-30 에서 끝난다** — 우리 구간 시작 하루 전이다. 라이선스도 미표기라
   그대로 쓸 수 없다.

## 3. GDELT — 이 환경에서 막혔다 (미완)

GDELT DOC 2.0 API 로 2023-03 구간 한국어 기사를 조회했으나 **HTTP 429 (Too Many
Requests)** 로 3회 연속 실패했다. 레이트 리밋이라 시간을 두고 다시 시도하면 열릴
수 있다. 다만 열리더라도 GDELT 는 **URL·제목·메타데이터만** 주고 본문은 주지 않는다.
본문을 얻으려면 기사 페이지를 긁어야 하는데, 그건 아래 "합법성" 절에서 배제한 경로다.
제목만으로 감성을 내는 축소안은 가능하지만 별도 결정이 필요하다.

## 4. 미검증 경로 — 여기에 유일한 희망이 있다

| 경로 | 커버 구간 | 접근 조건 | 비고 |
|---|---|---|---|
| **빅카인즈**(한국언론진흥재단) | 1990~현재, 국내 주요 언론사 | 회원 가입 + 이용 신청·승인 | 국내 뉴스 아카이브의 사실상 표준. **승인까지 시간이 걸린다** |
| 네이버 뉴스 검색 API | 미확인 | 애플리케이션 등록(무료) | 쿼리당 최대 1,000건·날짜 구간 필터가 없어 과거 도달이 제한적일 가능성이 높다 |

## 5. 월별 확보 가능 기사 수 추정

조사한 **접근 가능한** 경로 기준이다.

| 구간 | 월별 확보 가능 건수 | 근거 |
|---|---|---|
| 2023-01 ~ 2025-12 (36개월) | **0** | 위 1~3절. 어떤 경로도 이 구간을 시각과 함께 주지 않는다 |
| 2026-09-10 이후 (수집 시작 시점부터) | 약 4,500 / 월 | RSS 실측 하루 150건 × 30일 |

특정 구간만 비어 있는 게 아니라 **36개월 전체가 비어 있다.** 그래서 구간 축소로
풀리지 않는다 — 최근 2년(2024-01~2025-12)도 똑같이 0이다.

## 6. 수집 경로의 합법성

Q1 에서 완화된 것은 **우리 DB 에 원문을 두는 것**이지 수집 방법이 아니다. 그 선을
지켰다.

- **RSS 피드만 읽는다.** 피드는 언론사가 배포(syndication)를 목적으로 공개한 것이고,
  본문은 피드가 주는 `description`/`content` 까지만 쓴다.
- **기사 페이지 스크래핑은 하지 않았다.** 이용약관·`robots.txt` 확인이 필요한
  영역이고, 애매하면 멈춰서 묻기로 한 원칙을 따랐다.
- 공개 데이터셋 중 **라이선스 미표기(`kospi100_news` 등)는 쓰지 않는다.** 구간이
  맞았더라도 그대로 가져다 쓸 수 없다.
- 졸업작품이라도 저작권 문제가 생기면 데모가 아니라 학교 문제가 된다.

## 7. 판정과 권고

**판정: 3년 확보 불가 · 2년 축소로도 해결 불가.**

근거 요약: RSS 최대 2일(실측) · 시각 있는 공개 데이터셋은 2022-12 에서 끝남(실측) ·
시각 없는 데이터셋은 as-of 규약상 사용 불가 · GDELT 는 본문 미제공(및 429) ·
빅카인즈/네이버 API 는 자격 증명 필요로 미검증.

권고 — 셋을 병행한다.

1. **즉시: 빅카인즈 이용 신청.** 2023-2025 국내 뉴스를 시각과 함께 얻을 수 있는
   유일하게 현실적인 경로다. 승인에 시간이 걸리므로 **오늘 신청하지 않으면 11월에
   손쓸 수 없다.** 승인되면 판정을 뒤집을 수 있다.
2. **동시에: 오늘부터 RSS 전방 수집을 시작한다.** 수집기는 이미 돈다(`scripts/
   ingest_news.py`). 하루 150건씩 쌓이므로 11월 데모까지 약 2개월치가 모인다.
   과거 백테스트에는 못 쓰지만, **"최근 N주" 짧은 구간의 감성 시연**과 운용 모드
   시연에는 쓸 수 있다.
3. **대비책(1이 실패할 경우): 감성 관점을 백테스트에서 중립 고정으로 후퇴.**
   3관점 경연이 2관점이 되는 것을 문서로 명시하고, 감성은 전방 수집 구간에서만
   살아 있는 것으로 데모를 구성한다.

**백테스트 구간(2023-01-01 ~ 2025-12-31)은 데모 계획 1.4 의 확정 사항이라 M3 혼자
바꿀 수 없다.** 위 판정을 팀에 올리고 결정을 받는다. 결정이 필요한 것은 구간 자체가
아니라 "감성 관점을 백테스트에서 어떻게 다룰 것인가"다.

## 다시 재야 할 것

- 네이버 검색 API 의 과거 도달 범위 (Client ID 발급 후)
- GDELT 429 해소 후 2023 구간 반환 여부 (제목만 쓰는 축소안을 검토한다면)
